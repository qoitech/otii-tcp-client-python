# Otii TCP Client for Python

The `otii_tcp_client` is a Python package for controlling the Otii software
from [Qoitech](https://www.qoitech.com) using
the [Otii Automation Toolbox](https://www.qoitech.com/automation-toolbox/).

Read more on how to use this software
in the [Otii documentation](https://docs.qoitech.com/en/user-manual/python-scripting).

Read more about the Qoitech products at [https://www.qoitech.com](https://www.qoitech.com).
